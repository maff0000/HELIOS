# The execution vocabulary HELIOS must never contain.
#
# HELIOS is execution-blind. This file is the machine-readable definition of
# that boundary; tests/test_execution_blind.py enforces it against every
# identifier, non-docstring string literal and fixture value in the tree.
#
# Two sections. BARE terms are forbidden as whole words. PATTERN terms are
# regular expressions for compound names that have no innocent reading.
#
# Prose is deliberately exempt: a docstring, a comment or a document must be
# able to NAME the boundary in order to explain it. Code and data must not
# cross it. This file itself is excluded from the scan for the same reason.
